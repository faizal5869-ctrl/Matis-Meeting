FS MEETING RECORDER — BINAAN SEMULA DENGAN TRANSKRIPSI

Pakej ini dibina semula; ia bukan salinan tepat ZIP lama yang sudah tiada.

LIMA FAIL
index.html, app.js, manifest.json, sw.js, README.txt

CARA GUNA DI TELEFON
1. Muat naik lima fail ini ke repository GitHub melalui Chrome telefon: cipta repository, buka Add file > Upload files dan pilih fail selepas ZIP diekstrak.
2. Dalam Settings > Pages, pilih Deploy from a branch, branch main, folder /(root), kemudian Save.
3. Buka URL GitHub Pages yang diberi menggunakan Chrome. HTTPS diperlukan.
4. Isi tajuk, tekan Mula rakaman dan benarkan mikrofon. Teks yang dikesan akan muncul dalam kotak teks.
5. Tekan Hentikan dan simpan. Audio dan teks akan tersimpan dalam pelayar telefon. Muat turun audio sebagai sandaran.

TRANSKRIPSI
Menggunakan Web Speech Recognition pelayar dalam Bahasa Melayu (ms-MY). Sokongan berbeza mengikut telefon/pelayar; sambungan internet biasanya diperlukan. Jika transkripsi tidak disokong atau terganggu, rakaman audio masih berjalan dan catatan boleh ditaip sendiri. Periksa serta betulkan teks selepas rakaman.

DATA DAN PRIVASI
Rakaman/audio disimpan secara setempat pada peranti ini dan tidak dihantar oleh aplikasi ke GitHub. Jangan padam data laman/Chrome sebelum membuat sandaran. Pastikan peserta tahu dan bersetuju sebelum rakaman.
