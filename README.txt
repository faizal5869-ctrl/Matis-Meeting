MATIS MEETING — PERAKAM DENGAN TRANSKRIPSI

Pakej ini ialah binaan semula aplikasi. Muat naik lima fail di dalam ZIP ke repository GitHub dan aktifkan GitHub Pages melalui Settings > Pages > Deploy from a branch > main > /(root).

CARA GUNA DI TELEFON
1. Buka laman GitHub Pages melalui Chrome dan HTTPS.
2. Isi tajuk, benarkan mikrofon, tekan Mula rakaman, kemudian Hentikan dan simpan.
3. Cipta kunci Gemini API di Google AI Studio. Jangan kongsi kunci itu.
4. Buka Kunci transkripsi dalam aplikasi, tampal kunci, kemudian tekan Tukar audio ke teks pada rakaman.
5. Teks dipaparkan di bawah mesyuarat dan disimpan dalam pelayar telefon.

PRIVASI DAN HAD
- Audio dihantar ke Google untuk transkripsi hanya selepas anda menekan Tukar audio ke teks.
- Kunci API hanya berada dalam memori halaman, tidak disimpan ke telefon atau fail GitHub. Tutup halaman untuk memadamkannya.
- Kunci API digunakan dalam pelayar ini; gunakan kunci khusus Gemini API dengan had penggunaan. Jangan masukkan kunci pada peranti awam.
- Penggunaan Gemini API mungkin tertakluk pada had akaun atau caj.
- Fail audio melebihi 13 MB perlu dipendekkan dahulu.
- Rakaman asal disimpan setempat dalam pelayar. Muat turun audio yang penting sebagai sandaran.
- Maklumkan peserta dan dapatkan persetujuan sebelum merakam atau menghantar audio untuk diproses.
